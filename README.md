# Arses Panel

پنل مدیریت کاربران با **حجم جداگانه برای نت ملی و نت بین‌الملل**، همراه با مانیتورینگ وضعیت اتصال.
بدون هیچ وابستگی خارجی (فقط Node.js).

## امکانات

- ساخت/ویرایش/حذف کاربر با سهمیه‌ی جدا برای نت ملی و بین‌الملل، تاریخ انقضا، فعال/غیرفعال
- داشبورد: آمار کاربران، مصرف کل هر دو شبکه، نمودار ۱۴ روز اخیر
- مانیتورینگ زنده: پینگ سایت‌های داخلی و خارجی و تشخیص حالت (کامل / فقط ملی / فقط بین‌الملل / قطع)
- لینک اختصاصی برای هر کاربر (`/u/<token>`) تا مصرف خودش را ببیند
- API ثبت مصرف برای سرویس/ایجنت شما (با API Key)
- ورود ادمین با کوکی امضاشده + محدودیت تلاش ناموفق

## دیپلوی روی Railway

1. پروژه را در یک ریپوی GitHub بگذارید (یا با `railway up` آپلود کنید) و روی Railway «New Project → Deploy from GitHub» بزنید.
2. در تب **Variables** این‌ها را بگذارید:
   - `ADMIN_USER` : نام کاربری ادمین (پیش‌فرض `admin`)
   - `ADMIN_PASS` : رمز ادمین (**حتماً تنظیم کنید**؛ اگر نگذارید یک رمز تصادفی در لاگ چاپ می‌شود)
   - `SECRET` : یک رشته‌ی تصادفی بلند برای امضای نشست (اختیاری)
   - `API_KEY` : کلید API ثبت مصرف (اختیاری؛ وگرنه خودکار ساخته می‌شود و در تب تنظیمات پیداست)
   - `DATA_DIR` : `/data`
3. برای اینکه داده‌ها با هر دیپلوی پاک نشوند، یک **Volume** بسازید و روی مسیر `/data` مونت کنید.
4. در تب **Settings → Networking** روی «Generate Domain» بزنید و آدرس را باز کنید.

## اجرای محلی

```bash
ADMIN_PASS=mypass node server.js
# http://localhost:3000
```

## API ثبت مصرف

```bash
curl -X POST https://YOUR-APP.up.railway.app/api/agent/report \
  -H "x-api-key: YOUR_API_KEY" -H "content-type: application/json" \
  -d '{"user":"ali","national":10485760,"international":52428800}'
```

مقدارها به **بایت** هستند و به مصرف فعلی اضافه می‌شوند. چند کاربر: `{"items":[{...},{...}]}`.
لیست وضعیت کاربران: `GET /api/agent/users` (با همان هدر).

## نکته

مانیتورینگ از داخل مرورگر شما اجرا می‌شود، پس وضعیت واقعی اینترنت همان دستگاه (نت ملی یا بین‌الملل) را نشان می‌دهد؛
هدف‌ها را از تب «تنظیمات» می‌توانید تغییر دهید.
